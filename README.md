# Telegram UserBot

Многофункциональный юзербот на Telethon с RP-командами, загрузкой медиа (YouTube / Instagram / TikTok) и стелс-функциями.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

### Переменные окружения

| Переменная | Описание |
|-----------|----------|
| `API_ID` | API ID из my.telegram.org (обязательно) |
| `API_HASH` | API Hash оттуда же (обязательно) |
| `OWNER_ID` | Telegram ID владельца (обязательно) |
| `STRING_SESSION` | Строка сессии Telethon (опционально) |
| `PORT` | Порт Flask-статуса (по умолч. 8080) |
| `MEDIA_DIR` | Директория для скачанных файлов (по умолч. ./media) |
| `BOT_LANG` | Язык ответов: `ru` (по умолч.) \| `en` |
| `MAX_FILE_SIZE_MB` | Лимит отправляемого файла, МБ (по умолч. 4096) |

### Загрузка медиа
| Команда | Описание |
|---------|----------|
| `!ytshow <URL> [качество]` | Скачать видео с YouTube |
| `!dl <URL>` | Скачать видео (YouTube / Instagram / TikTok); можно **ответом на сообщение со ссылкой** |
| `!playlist <URL> [кол-во]` | Скачать плейлист YouTube |
| `!audio <URL> [128\|192\|320] [voice\|file]` | Аудио с YouTube: битрейт, отправка голосовым/документом |
| `!sub <URL> [язык]` | Скачать субтитры (умолч. ru) |
| `!ytupdate` | Принудительно обновить yt-dlp, если YouTube сломал скачивание |

Во время загрузки показывается прогресс: `█░`-бар, проценты, скорость и ETA.
Загрузки идут в очереди с указанием позиции; разные платформы качаются параллельно,
две загрузки с одной платформы — последовательно.

### Онлайн-следка (ONWATCH)
| Команда | Описание |
|---------|----------|
| `!onwatch @user\|ID <текст>` | Отправить текст, как только цель окажется в сети |
| `!onwatchlist` | Список активных треков (с текущим статусом) |
| `!unonwatch @user\|ID` | Снять отслеживание |

Каналы детекции (максимальная точность): опрос статуса раз в 10 с, мгновенные
статус-апдейты Telegram, typing-апдейты и входящие сообщения цели — последнее
работает даже если цель скрыла online-статус («был(а) недавно»).

### RP-команды

Работают **только в личных сообщениях**. Для отправки RP-действия:

- **Любой пользователь** в ЛС — пишет команду, бот отвечает
- **Owner/Sudo** — реплай на чьё-то сообщение с командой (RP от имени бота к этому человеку)

Более 90 RP-действий. Список: `!rphelp`

## Зависимости

- `telethon` — работа с Telegram API
- `yt-dlp` — загрузка YouTube / TikTok / Instagram (видео, аудио, карточки)
- `curl_cffi` — обязателен для TikTok/Instagram (имперсонация браузера в yt-dlp)
- `requests` / `aiohttp` — HTTP-запросы
- `flask` — веб-статус

## Структура

```
├── main.py          # Bootstrap: Flask /stats, стартовые задачи, загрузка плагинов
├── plugins/         # Команды, сгруппированные по доменам (14 модулей)
│   ├── system.py    #   статус, пинг, sudo, рестарт…
│   ├── stealth.py   #   ghost/cover/silent/shadow…
│   ├── media.py     #   !dl / !audio / !playlist / !ytupdate…
│   ├── watch.py     #   !onwatch + поллер статусов
│   └── …            #   profile, games, toolbox, messages, datanote, afk,
│                    #   chatinfo, security, rp, menu
├── helpers.py       # Общие функции (сущности, FloodWait, карточка статуса)
├── core.py          # Состояние бота, owner_filter, respond, кулдауны
├── config.py        # Конфигурация и константы
├── help_data.py     # Справка и меню с кнопками
├── downloaders.py   # Загрузчики YouTube / Instagram / TikTok (прогресс, очередь)
├── notifier.py      # Внешний уведомляющий бот
├── rp_commands.py   # RP-команды (словари)
├── storage.py       # Хранилище (SQLite)
├── tests/           # Юнит-тесты: python -m unittest discover -s tests -v
├── requirements.txt # Зависимости
├── build.sh         # Скрипт сборки для хостинга
└── media/           # Папка загрузок
```

## Статистика и тесты

- `GET /stats` — JSON-дашборд (команды, треки onwatch, напоминания, размер media/).
- Тесты: `python -m unittest discover -s tests -v` (без .env не требуются).
